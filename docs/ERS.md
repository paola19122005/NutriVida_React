# ERS - NutriVida

## Roles
- Administrador: gestiona servicios y usuarios.
- Nutricionista: gestiona pacientes, planes y citas.
- Paciente: consulta su perfil, servicios, planes y seguimiento.

## Requisitos funcionales implementados
- RF1 Inicio de sesión y control por rol.
- RF2 Catálogo de servicios.
- RF3 Lista de servicios seleccionados con fecha y estado.
- RF4 Pagoo simulado.
- RF5 Mantenedor de servicios (CRUD).
- RF6 Mantenedor de usuarios (crear, editar, activar/desactivar, eliminar).
- RF7 Panel nutricionista y edición de plannes/citas.
- RF8 Perfil paciente con categorías y detalle de plan.
- RF9 Validaciones de formularios.
- RF10 Búsqueda en catálogo, servicios y usuarios.

## Requisitos no funcionales
- RNF1 Aplicación React + Vite + TypeScript.
- RNF2 Atomic Design.
- RNF3 Responsive con Bootstrap y CSS.
- RNF4 Persistencia en localStorage.
- RNF5 Pruebas con Vitest.
