## Flujo sugerido
1. Iniciar sesión como paciente y mostrar perfil, servicios, plan y feedback.
2. Iniciar sesión como nutricionista y mostrar panel, planes y citas.
3. Iniciar sesión como administrador y mostrar mantenedores.
4. Mostrar catálogo, búsqueda y lista.
5. Mostrar pago simulado.
6. Ejecutar `npm run test` y `npm run test:coverage`.
7. Mostrar responsive en móvil/tablet.
